Project & Methodology

About the Movie Recommendation System

A machine learning study evaluating Collaborative Filtering (SVD) and Deep Neural Networks (NCF) on the MovieLens Latest dataset.

Architecture & Design

This system models complex non-linear user-movie interactions by combining traditional matrix factorization with deep representation learning. While standard Singular Value Decomposition (SVD) relies on linear inner products, our Neural Collaborative Filtering (NCF) architecture employs the NeuMF framework, fusing:

  • Generalized Matrix Factorization (GMF): Captures linear latent relationships between user and item embedding representations.
  • Multi-Layer Perceptron (MLP): Extracts deep, non-linear interaction patterns through stacked dense layers with non-linear activations.

Trained on 32+ million real-world user interactions, the model generates personalized Top-N recommendation sets filtered by user viewing histories and content constraints.
